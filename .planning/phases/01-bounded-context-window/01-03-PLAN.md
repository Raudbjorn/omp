<task id="2" title="Add bounding and exclusion marker tests to message-transform">
<read_first>
- packages/coding-agent/test/message-transform.test.ts (existing transform tests — segmentation, stubbing, dropping)
- packages/coding-agent/src/context/assembler/message-transform.ts (transformMessages, TurnDecision, TransformMetadata)
</read_first>
<action>
Add test cases to `message-transform.test.ts`:

1. **BOUND-01 — Token-based cap:**
   - Create a conversation with 20+ turns totaling ~200K estimated tokens
   - Call `transformMessages()` with `recentMessageCap: 150000`
   - Assert: total estimated tokens of returned messages <= 150000
   - Assert: metadata.droppedCount > 0
   - Assert: metadata.keptCount < total turns

2. **BOUND-02 — Tool transcript exclusion:**
   - Create a conversation with tool call/result pairs in older turns
   - Call `transformMessages()` with a cap that excludes the older turns
   - Assert: returned messages do NOT contain any tool_result content from excluded turns
   - Assert: excluded turns have `action: "dropped"` in decisions (not `"stubbed"`)

3. **BOUND-03 — Exclusion markers:**
   - Use same setup as BOUND-01 with some turns excluded
   - Assert: returned messages contain a text message matching pattern `excluded:` and `recover`
   - Assert: the marker mentions the correct turn range (e.g., "Turns 1-15 excluded")
   - Assert: only one marker per contiguous exclusion block

4. **OBSV-01 — Decision metadata completeness:**
   - After transformMessages(), assert metadata.decisions is an array
   - Each decision has: turnIndex (number), action (one of 'kept'|'stubbed'|'dropped'), reason (string), tokensBefore (number >= 0)
   - Total decisions count === metadata.totalTurns
   - Sum of keptCount + stubbedCount + droppedCount === totalTurns

5. **Edge case — all turns fit within cap:**
   - Small conversation (~10K tokens) with recentMessageCap: 150000
   - Assert: all turns kept, droppedCount === 0, no exclusion markers
</action>

- `message-transform.test.ts` contains test for tool transcript exclusion
